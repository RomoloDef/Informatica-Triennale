# 📑 Appelli d'Esame Completi

Questa cartella raccoglie le prove d'esame integrali in formato PDF somministrate negli appelli passati di **Architettura degli Elaboratori**.

Ogni prova d'esame è strutturata in tre parti complementari che testano la preparazione su:
1. **Esercizio 1**: Gerarchia di memoria (Cache L1/L2, AMAT, calcolo hit/miss, paginazione).
2. **Esercizio 2**: CPU RISC-V a ciclo singolo (aggiunta di una nuova istruzione al datapath, tabella dei segnali e codifica binaria).
3. **Esercizio 3**: CPU RISC-V con pipeline a 5 stadi (con e senza forwarding, hazard sui dati e sul controllo, calcolo cicli totali).
