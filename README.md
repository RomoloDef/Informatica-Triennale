## 🔍 Come Utilizzare Questa Repository

1. **Naviga** nella cartella dell'anno e del corso che ti interessa
2. **Scarica** i singoli file oppure clona l'intera repository:
   ```bash
   git clone https://github.com/RomoloDef/Informatica-Triennale.git
   ```
3. **Studia** combinando il materiale qui presente con le risorse ufficiali dei corsi

> [!TIP]
> I corsi più completi e ricchi di materiale sono: **Fondamenti di Programmazione**,**Architettura degli Elaboratori**, **Basi di Dati**, **Organizzazione e Gestione per lo Start-Up Aziendale**, **Sicurezza**, **Interazione Uomo Macchina** e **Programmazione per il Web**.

## ⚠️ Disclaimer

- Il materiale presente in questa repository è fornito **così com'è** (*as-is*), senza garanzie di completezza o correttezza.
- Alcuni corsi contengono **poco o nessun materiale**: questa repository è nata come cartella personale e non tutti i corsi sono stati documentati allo stesso modo.
- Le slide e le dispense dei docenti sono incluse **esclusivamente a scopo didattico e di studio personale**. Se sei un docente e desideri che il tuo materiale venga rimosso, contattami e provvederò immediatamente.
- I programmi dei corsi possono **variare di anno in anno**: verifica sempre con il programma ufficiale del tuo anno accademico.

## 🤝 Contribuire

Se hai materiale aggiuntivo, appunti, esercizi o correzioni da condividere, ogni contributo è benvenuto!

1. **Forka** questa repository
2. **Crea un branch** per le tue modifiche (`git checkout -b aggiungi-materiale-nomeCorso`)
3. **Committa** le modifiche (`git commit -m "Aggiunto materiale per NomeCorso"`)
4. **Apri una Pull Request** descrivendo cosa hai aggiunto

In alternativa, puoi semplicemente aprire una **Issue** segnalando errori o suggerendo miglioramenti.
