    --> 

    L = lat' - lat 

    Lo = long' - long 

    a = sin^2(L/2) + cos(lat) + cos(lat') * sin^2(Lo/2)

    c = 2 * 2arctan(sqrt(a), sqrt(1-a))

    R = 6371

    d = result = R * c
    

    (questa è la formula per calcolare la distanza)
